Role: Audio Plugin Developer

Job description

Overview

Designs, builds and tests audio effect plugins that run inside digital audio workstations (DAWs). Turns signal processing ideas into reliable, great-sounding tools that musicians, producers and mix engineers can use in real production work.

Responsibilities

  • Design and implement digital signal processing (DSP) algorithms for dynamics, filtering, saturation and modulation effects.
  • Build plugins that run in real time with low latency and stable CPU use.
  • Create clear parameter controls and user interfaces that are easy to use during a session.
  • Test and validate plugins inside the host DAW, including loading, automation and saving of presets and sessions.
  • Listen critically and tune the sound by ear, balancing technical accuracy with musical results.
  • Document, package and maintain plugins so they are simple to install and update.

Skills & tools

  • C++
  • Digital signal processing
  • Audio plugin development
  • Real-time audio
  • Plugin UI design
  • DAW testing

What I bring

A musician's ear and a developer's discipline. As a keyboardist, I know what a tool needs to feel like in a session, and I build effects with that in mind.
